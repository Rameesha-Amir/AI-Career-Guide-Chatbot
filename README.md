# AI-Career-Guide-Chatbot
An interactive, AI-powered career counselor that helps users explore professional paths based on their interests. This project leverages Machine Learning (NLP) and the Flask web framework to provide a seamless guidance experience.

✨ Key Features
Intelligent Classification: Uses a LinearSVC (Support Vector Machine) model to understand user intent rather than just matching keywords.

10+ Career Fields: Detailed roadmaps for Medical, AI/Tech, Law, Engineering, Design, and Business.

Step-by-Step Roadmaps: Provides clear academic and professional paths from high school to the job market.

Modern UI: Features a clean, responsive chat interface with quick-action buttons and real-time typing indicators.

🛠️ Tech Stack
Backend: Python (Flask)

Machine Learning: Scikit-Learn (TF-IDF Vectorization, Linear SVM)

Frontend: HTML5, CSS3 (Modern UI/UX), JavaScript
